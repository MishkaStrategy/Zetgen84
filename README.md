# Zetgen-84 × СПУТНИК — коммерческое предложение

Одностраничный интерактивный сайт-коммерческое предложение дизайн-агентства **СПУТНИК** для бренда **Зетген-84**.

## Стек

- чистый HTML / CSS / JavaScript без тяжёлых зависимостей;
- адаптивная 12-колоночная композиция;
- scroll-driven горизонтальные кейсы;
- sticky-секции, reveal, parallax и progress-анимации;
- локальный product shot реальной упаковки Зетген-84.

## Запуск

Откройте `index.html` локально или раздайте корень репозитория любым статическим хостингом.

## Примечания

В секции отзывов используются демонстрационные фрагменты обратной связи как композиционные заглушки до передачи утверждённых скриншотов СПУТНИК. Бизнес-результаты в кейсах сформулированы качественно, без вымышленных процентов и гарантий. Продуктовые медицинские утверждения намеренно не используются; перед публичным запуском рекламные формулировки следует сверить с маркировкой и применимыми требованиями.
