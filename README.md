# Zetgen-84 — 3 redesign concepts

Static prototype with three visual directions for the new Zetgen-84 website.

- `variant-1.html` — Bio Glass: biotech + liquid glass + gradients.
- `variant-2.html` — Siberian Editorial: natural premium + editorial typography.
- `variant-3.html` — NeoLab Performance: high-contrast digital/performance direction.
- `index.html` — concept selector.

The prototype uses product images hosted on the current public website and intentionally softens medical/therapeutic claims. Before production launch, product copy should be reviewed against actual product labeling, declarations, and applicable advertising/legal requirements.
